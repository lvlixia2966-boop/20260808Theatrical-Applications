## 1. 评审结论摘要

### 1.1 三方共识

1. **同传收听席是真实护城河**，精准踩中 2025-2026 三大风口：入境免签潮（2025 入境外国人 8203 万人次 +26.4%）、演出经济（票房 616 亿，1 元带动 6.85 元综合消费）、非遗热（非遗电商年成交破千亿）。
2. **项目当前是「演示态」而非「产品态」**：支付沙盒、优惠码静态、进度存本地、数据全盲、内容靠改代码。
3. **下一阶段主线**：把「钱（核销/支付）、身份（进度上云）、数据（埋点）」三条线接通，再谈扩张。

### 1.2 高置信机会（多源交叉验证）

| 机会 | 证据 | 现状 |
|---|---|---|
| 集章打卡是外国游客真实新宠 | China Daily / Straits Times 报道景区盖章热 | 川剧护照已上线，缺实体联动与回流钩子 |
| 变脸是最大流量符号 | IShowSpeed 访蓉视频全球刷屏、TripAdvisor 核心好评点 | 变脸小游戏/彩蛋已上线，缺短视频传播物 |
| 票根经济被官方背书 | 成都世运会 6 大类 44 项权益模型 | 未接入，购物点导览可反向改造 |
| 境外游客支付摩擦是第一痛点 | Global Times 及学术研究 | 支付为沙盒，商户号未接 |
| iPhone 不支持 Web Bluetooth | 平台限制 | 准入页全屏锁死，仅 skip 旁路 |

### 1.3 安全前置（2026-09-08 排查结论，上线硬门槛）

P0：admin 弱口令已实测可登录、支付模拟接口无鉴权、root 口令在代码仓库；
P1：TTS/翻译/伴游无限流、JWT 无吊销、无 HTTPS。

## 2. 实施路线图

### 第 0 批 · 上线前置（1 周内，硬门槛）

| # | 任务 | 改动点 | 验收标准 | 量 |
|---|---|---|---|---|
| 0.1 | 管理员弱口令整改 | 222 数据库 admin 口令更换 + 种子脚本移除固定口令 | admin123 登录返回 401 | S |
| 0.2 | 支付接口收紧 | `/api/payments/*` 下单/确认接口加管理鉴权或仅非生产注册；mock confirm 生产关闭 | 未授权调用返回 401/404 | S |
| 0.3 | 豆包语音凭据接入 | 容器 env 补 `DOUBAO_SPEECH_APP_ID/ACCESS_TOKEN`，`TTS_ENGINE=edge→auto` | `/api/tts/synthesize` 返回 200 + 音频 | S |
| 0.4 | 基础限流 | TTS/翻译/Agent/旅拍按 IP 限流中间件（如 60 次/时）；TTS text 长度上限 | 超限返回 429 | S |
| 0.5 | 凭据出仓 | 部署脚本 root 口令改 SSH key；`.env` 模板化 | 仓库 grep 不到明文口令 | M |
| 0.6 | HTTPS + 管理口令策略 | 局域网自签证书或反代 TLS；登录失败限流 | 管理台走 https | M |

## 3. 里程碑与依赖

```
第 0 批（安全/凭据）──┬─→ 第 1 批（闭环：身份/核销/埋点）──┬─→ 第 2 批（运营基建）──→ 第 3 批（增长/商业化）
                      └─→ 3.5 旅拍付费（支付就绪即可并行）
关键依赖：商户号接入是 3.6 前置；票根联盟是商务合作项，可与第 2 批并行洽谈；
题库后台化（2.1）是玩法长期运营的前置；进度上云（1.1）是核销与归因的前置。
```

## 4. 明确不做（本期）

- 不新增纯演示态子板块
- 不在真实商户号接入前启用任何真实收费
- 不做原生 App（H5 已覆盖场景，扫码即用是入境游客最友好形态）
