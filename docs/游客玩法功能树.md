## 附：跨模块事件与存储约定（本扩展新增/依赖）

| 名称 | 类型 | 派发方 | 订阅方 | 说明 |
|---|---|---|---|---|
| `app:live:joined` | window 事件 | live-listen.js `enterListen()`（新增一行） | passport.js | 进入场次直播收听席 |
| `app:quiz:passed` | window 事件 | quiz.js 结果页（≥3 题） | passport.js | detail: `{ score }` |
| `app:passport:stamp` | window 事件 | passport.js 授章成功 | 入口卡刷新 / 后续营销位 | detail: `{ id }` |
| `ble:connected` / `app:order:paid` | window 事件 | ble-guard / checkout（既有） | passport.js | 复用既有事件 |
| `chuan_passport` | localStorage | passport.js | — | `{ 印章id: 时间戳 }` |
| `chuan_quiz_best` | localStorage | quiz.js | — | 历史最佳答对数 |
