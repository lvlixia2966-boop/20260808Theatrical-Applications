## 1. 产品定位

面向**进入四川省川剧院现场**的观众（尤其境外/非川剧观众）的多语言智能剧场服务：
一台租来的专用耳机 + 一次扫码，覆盖**入场前 → 观剧中 → 散场后**的完整体验闭环。

一句话：**「扫码即得同声传译，文创商城一键带走川剧记忆」**

## 2. 目标用户

| 用户群 | 核心诉求 | 对应能力 |
|---|---|---|
| 境外游客 | 听不懂中文唱词，需要母语同传 | 耳机收听席：原声 + 24 语种字幕/译文播报 |
| 普通观众/游客 | 了解川剧文化、便捷观剧 | 16 语种剧场介绍、变脸等绝技看点推送 |
| 年轻观众/文创爱好者 | 把川剧记忆带走 | 文创商城、AI 旅拍换装、众创平台 |
| 剧院管理方 | 场次无人值守、设备可管、内容可运营 | 管理后台、场次调度器、耳机管理 |

## 3. 用户旅程（核心场景）

```
门口柜台租耳机（线下付费，耳机即凭证）
   │
   ▼ 扫码进入服务页
【准入页】选语言 → 连接专用蓝牙耳机（CHUAN-*，自动读电量）
   │        └ 低电量提醒充电 / 断连自动重连 / 失联回退准入页
   ▼ 解锁正式页面（首页）
【观剧】剧场介绍（16 语种语音）· 节目单 · 皮金滚灯同传演示
【收听】直播收听席：现场原声 + 原文/译文对照字幕流
   │        ├ 变脸/吐火/滚灯等绝技看点卡片（60s 冷却，8s 自动收起）
   │        ├ 关屏降级：锁屏后自动转播预合成译文音频（媒体卡片可控）
   │        └ 收播引导卡 → AI 旅拍
【文创】商城购物车（结算支付）· 购物点导览 · 众创平台 · AI 旅拍 · 知识图谱 · VR 展馆 …
【散场】归还耳机即结束；文创订单线上留痕
   │        └ 川剧护照集章贯穿全程（8 章）：连耳机/听介绍/试听滚灯/问伴游/进收听席/旅拍/下单/竞答通关
   │          └ 候场·中场：观演知识竞答（通关 → 护照印章 + 文创九折码）
```

## 5. 体验设计原则（贯穿性约定）

1. **一码一耳机一语言**：用户只做两个动作——扫码、戴耳机，其余全自动。
2. **零操作同传**：进场即推流字幕，无需任何点击；译文播报为可选项。
3. **所有面向用户的文案多语言化**：UI 文案接入 i18n 词典（7 语种），介绍内容 16 语种手写预置（禁机翻），医院等歧义词黑名单硬拦。
4. **耳机即准入**：未连接专用耳机不放行正式页面；耳机在柜台线下租用，线上不收费。
5. **关屏不打断**：点播音频锁屏续播（媒体卡片），收听席屏幕常亮，锁屏后降级播预合成译文。
6. **高内聚低耦合**：功能均为自治 JS 模块（CustomEvent 通信）/ 后端 service 域，互不侵入。

## 6. 商业化路径

| 收入线 | 形式 | 现状 |
|---|---|---|
| 耳机租售 | 柜台押金制租用 / 销售 | 线下进行，系统仅做准入校验 |
| 文创商城 | 商城购买（微信/支付宝/PayPal） | 沙盒链路已通，待商户号 |
| AI 旅拍 | 拍照生成 + 付费精修/打印 | 演示功能 |
| IP 众创 | 设计师入驻、版权分成 | 规划（见商业化方案文档） |

## 7. 数据与运营指标（建议）

- 准入转化：扫码 → 连接耳机成功 率
- 同传使用：收听席进入率、字幕接收条数/场、各语言占比
- 商城：加购率、结算转化率、客单价（订单表已具备埋点基础）
- 介绍触达：剧场介绍播放完成率、各语言占比

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 现场网络无法访问境外 CDN | 字体/静态资源全自托管（已落地）；国内可直连镜像下载依赖 |
| 浏览器自动播放策略 | 播放均由用户手势触发；AudioContext 首帧手势解锁 |
| iOS 后台限制 | 点播走媒体卡片续播；收听席走保屏 + 关屏降级译文 |
| 机翻品牌事故 | 关键内容手写预置 + 术语韵译库 + 黑名单后检（历史教训已固化） |
| 容器重建丢改动 | 宿主源码同步后再 rebuild（运维约定，见架构文档 §7.1） |
