## 1. 背景与目标

### 1.1 问题

现产品覆盖「观演中 90 分钟」非常扎实（同传、字幕、看点推送），但游客旅程存在三段空白：

| 空白时段 | 现状 | 后果 |
|---|---|---|
| 候场/中场（约 30 分钟） | 只有剧场介绍一次性内容 | 无聊、低头玩手机，剧场氛围断档 |
| 离场瞬间 | 收播仅一张静态旅拍引导卡 | 情绪高点没有承接，流失快 |
| 离场后 | 无任何回访/传播触点 | 复访与口碑全靠自发 |

### 1.2 目标

把单一「观演场景」扩展为「到场前 → 候场 → 观演 → 离场 → 离场后」的完整玩法旅程：

1. **停留**：给候场/中场一个 3 分钟级别的轻互动（竞答）；
2. **收集**：给散落的体验动作一个可积累的载体（护照印章），提升全功能渗透率；
3. **传播**：护照与称号是天然的社交展示物（朋友圈/Instagram），离场后继续带客；
4. **转化**：印章与竞答奖励统一导向文创消费（九折码 → 文创商店核销）。

### 1.3 设计红线（本期硬约束）

- **不打扰主线**：无悬浮球、无弹窗打断、无强制引导；入口仅「个人中心一张卡 + 竞答一张卡 + 授章 toast」。
- **零后端依赖**：一期全部纯前端（localStorage），任何网络/后端故障不影响主流程。
- **多语言**：界面与内容 zh/en 双语，未列语言回退英文；跟随全局 `app:langchange`。
- **视觉同源**：全部复用川剧深红金设计语言（印章/书法标题/底部抽屉），与伴游卡、准入页一致。

## 2. 用户旅程与玩法定位

```
门口租耳机 → 扫码准入（选语言、连耳机）
   │                            └─🪪 护照开册（耳机接引章）
   ▼
【候场 30min】剧场介绍 🪪 → 皮金滚灯试听 🪪 → 伴游提问 🪪 →（新）观演竞答 🪪🏆
   ▼
【观演 90min】收听席实时同传 🪪 → 绝技看点卡片
   ▼
【中场/散场】文创浏览下单 🪪 → AI 旅拍 🪪 →（新）购物点导览：散场去哪吃/逛/买
   ▼
【离场后】护照 8/8「川剧知音」→ 分享炫耀 → 文创九折码到店核销 → 口碑回访
```

三个模块各司其职：

| 模块 | 旅程位置 | 一句话定位 | 核心指标 |
|---|---|---|---|
| 川剧护照 | 全程贯穿 | 「今天在剧院做过的每件事都算数」 | 8 章渗透率、集满率 |
| 观演竞答 | 候场/中场/散场 | 「3 分钟看懂川剧」 | 参与率、通关率、券核销 |
| 购物点导览 | 散场决策 | 「出了剧院门去哪儿」 | 卡片点击、到店（后期靠券核销归因） |

## 3. 玩法细则

### 3.1 川剧护照（集章）

- **印章即行为奖励**：8 枚章一一对应产品的 8 个核心动作（连耳机/听介绍/试听滚灯/问伴游/进收听席/旅拍/下单/竞答通关）。游客每自然使用一个功能就被「盖一枚章」，无需额外操作——收集感是「顺手」获得的，这正是「不打扰主线」的实现方式。
- **未集章显示完成条件**（如「向智能伴游提一个问题」），印章墙同时是功能导览页。
- **仪式感细节**：已集章带日期戳（获得于 YYYY.MM.DD）与微倾斜的红印质感；集满 8 枚触发彩蛋 toast。
- **技术形态**：`localStorage('chuan_passport')`，事件驱动授章（`ble:connected` / `app:order:paid` / `app:live:joined` / `app:quiz:passed` + 三处点击委托 + 包装 `generateAiPhoto`），授章幂等。

### 3.2 观演知识竞答

- **轻量快节奏**：随机 5 题、3 选 1、即时对错反馈，全场约 2-3 分钟——正好是中场休息的长度。
- **低门槛**：题库覆盖「看过今晚演出/听过介绍就能答对」的常识题（变脸是特技、红色脸谱是忠勇、盖碗茶三件套），不做刁难题；通关线 3/5。
- **双奖励**：通关 = 护照「懂戏之人」章 + 文创九折邀请码（CHUAN-GOLD-9，一期为静态演示码）。
- **称号体系**：5→巴蜀名角 / 4→川剧知音 / 3→戏剧新秀 / <3→初入门，结果页书法大字呈现，天然适合截图分享。
- **题库运营**：10 题内置前端（zh/en 手写双语）；二期接知识库验收问集（`EvalQuestion`）后台出题。

### 3.3 购物点导览

- **散场决策场景**：6 个点位按「步行/车程时间」标注（0/8/10/12 分钟），游客散场时按剩余体力选目的地。
- **类型搭配**：剧院自有（文创商店）+ 茶馆（鹤鸣）+ 非遗体验（蜀绣工坊）+ 街区（宽窄巷子/文殊坊）+ 商圈（太古里），覆盖「买伴手礼 / 喝茶消食 / 亲子 / 夜生活」四种散场意图。
- **与玩法打通**：文创商店卡注明「竞答九折码适用」，把线上玩法导流到线下第一站（剧院大堂），再自然外溢到周边。

## 4. 商业化路径

| 阶段 | 动作 | 依赖 |
|---|---|---|
| 一期（已上线） | 玩法闭环 + 演示码，验证参与率 | 无 |
| 二期 | 九折码接后端一次性核销（柜台扫码验券），按核销归因竞答/护照的带货效果 | 支付域既有 `payment_service` + 小型 coupon 表 |
| 二期 | 集满 8 章兑换实体（脸谱贴纸/书签）或数字纪念票，成本可控的复访钩子 | 柜台核销同上 |
| 三期 | 购物点商家侧联动：周边商户提供「护照持有人折扣」，剧院收取联名费用 | 商务合作 |
| 三期 | 称号/护照分享图带剧院二维码，投放社媒引流 | 前端海报合成（可复用旅拍管线） |

## 5. 数据指标（建议埋点）

一期纯前端无埋点；二期建议最小指标集：

| 指标 | 定义 | 用途 |
|---|---|---|
| 章参与率 | 领取过 ≥1 章的会话 / 总会话 | 玩法整体吸引力 |
| 单章渗透率 | 各章拥有量排序 | 发现被冷落的功能（章即功能漏斗） |
| 集满率 | 8/8 会话占比 | 长线目标健康度 |
| 竞答参与率/通关率 | 打开抽屉 / 通关 ≥3 题 | 题目难度校准 |
| 券核销率 | 核销数 / 发放数 | 玩法→文创转化（需二期核销码） |
| 购物点点击 | 各卡点击量 | 商务谈判依据 |

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 玩法打扰观演主线 | 已按红线设计（无悬浮球/无打断）；后续任何入口增加需评审 |
| localStorage 清缓存后进度丢失 | 一期可接受（单日游程为主）；二期账号/票务码绑定同步 |
| 演示码被当真传播 | 文案明示「向工作人员出示」；二期换一次性核销码时旧码自然失效 |
| 题库透题（答案传抄） | 题池扩容 + 后台化后可轮换；现状 10 题随机 5 题已保证基本新鲜度 |
| 境外游客语言 | zh/en 已覆盖；题库/印章名后续按 16 语 intro 模式逐语手写 |

## 7. 二期路线图（建议顺序）

1. **核销码后端化**（把九折码从「演示」变「真优惠」，打通玩法→消费闭环）
2. **护照分享图**（离场传播抓手，复用旅拍生图管线）
3. **题库后台化**（管理后台出题/轮换，接知识库验收问集）
4. **前后台探秘音频线**（开演前 30 分钟候场内容，复用 TTS 多语言）
5. **脸谱 DIY 生成器**（AI 旅拍同款管线，产出可下单印制，接商城闭环）
