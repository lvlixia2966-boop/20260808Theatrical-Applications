# 四川省川剧院 · 智能剧场应用 策划文档

> 2026-09-10 · 基于本周全部开发实践整理

---

## 1. 产品定位

面向进入四川省川剧院现场的观众（尤其境外游客），以「一副租用耳机 + 一次扫码」覆盖 **候场→观演→散场→离场后** 的完整体验闭环。

核心价值主张：**不懂中文，也能看懂整晚川剧。**

## 2. 架构决策

| 决策 | 理由 |
|---|---|
| 单页应用（无框架） | 扫码即用免安装；Tailwind 自托管零外网依赖 |
| 音频走后端 WS 不走蓝牙 | 200 人高密度蓝牙必崩；耳机只做接收终端 |
| 各模块独立 IIFE 自注入 | 零打包工具、零构建步骤、引即启用 |
| localStorage 优先 | 无账号体系下最快交付；后续耳机编号上云 |
| 事件驱动模块通信 | app:langchange / ble:connected / app:live:* 解耦 |

## 3. 本周核心交付

### 3.1 情境引擎（此情此刻此景）

应用从「游客找功能」升级为「知道游客在哪、演到哪、什么状态」的随身陪看。

阶段状态机：`候场 → 开场 → 进行 → 中场(字幕静默>4min) → 压轴(≤8min) → 散场`

每个阶段绑定一张情境卡（30 字内），零新增弹层，演出中零打扰。

### 3.2 视听 × 文创联动

绝技看点卡底部自动追加相关文创小链接；散场收播卡按本场看过的绝技推送商品条——推送的不是广告，是游客刚刚看过的东西的纪念。

### 3.3 游客玩法

川剧护照（8 章事件驱动）+ 观演竞答（五题三选一）+ 变脸挑战（三关眼力）+ 观剧记忆卡（Canvas 海报）。全部纯前端、零后端依赖、事件驱动接护照。

### 3.4 视觉体系

暖黑编辑风：衬线大字 + 金线 + 噪点纹理 + 单点追光。无框架依赖，17.7KB 单文件。

## 4. 技术规范

| 规范 | 标准 |
|---|---|
| 字号阶梯 | 12/14/16/20/32（下限 11px） |
| 间距 | 8pt 倍数（8/16/24/32/48/64/96） |
| 色彩 | 暖黑 #16120E + 米白 #F3EBDD + 朱红 #C43C31 + 描金 #C9A25E |
| 图标 | Lucide 统一（禁 emoji 做界面图标） |
| 动效 | 150-300ms ease-out；reduced-motion 全降级 |
| 中式元素 | 留白≥50%、印章≤2 处、纹样垫底 3%-8%、书法只做标题 |
