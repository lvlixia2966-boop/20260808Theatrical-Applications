# 川剧院数智文创 · 众创平台商业化运营策划方案

> 版本：v1.0
> 日期：2026-08-18
> 适用范围：众创平台（任务广场 / 数据库 / 工作台）及关联模块（IP 资产库、IP 铸造、文创商城、AI 旅拍）

---

## 一、背景与定位

### 1.1 现状

众创平台目前已具备完整的产品骨架：

- **任务广场**：脸谱 MBTI 测试、短视频挑战、川剧剧本杀、数字化修复
- **数据库**：川剧智库、Skills 库（技艺课程）、数字资产库（共创素材）
- **工作台**：3DGS 预览、虚实轻剧 1.0、创意工坊 2.0（多 Agent 协同）、智能体矩阵配置

产品能力已就绪，但缺少让用户"持续来、主动做、赚到钱"的商业化运营体系。

### 1.2 定位

**平台不是外包市场，而是"数字科班"**——用户不是来打工的，是来"入班学艺"的。
把川剧科班的师徒传承概念产品化，形成"参与 → 成长 → 变现 → 反哺非遗"的价值飞轮。

### 1.3 对标参考

| 对标对象 | 可借鉴点 |
|---|---|
| LiblibAI（哩布哩布） | 算力/分成经济模型、创作者空间、Skill Hub 工作流售卖、千万现金激励池 |
| 抖音非遗合伙人计划 | 官方任务 + 流量扶持 + 现金奖池的冷启动打法 |
| "AI 遇见非遗"众创计划 | 多省联动、高校产教融合、算力补贴 + 导师带教 |
| 故宫文创 / 敦煌 IP | IP 授权 + 实体文创的变现天花板验证 |

## 二、核心逻辑：价值飞轮

```
        ┌──────────────────────────────────────┐
        │                                      │
   参与任务 ──► 获得戏份/成长 ──► 解锁变现通道 ──► 赚取收益
        ▲                                      │
        │                                      ▼
   反哺非遗（修复/课程/新作品）◄── 更高等级权益/官方资源倾斜
```

四个环节缺一不可：
- 只有参与没有成长 → 用户流失（没有目标感）
- 只有成长没有变现 → 用户流失（为爱发电不可持续）
- 只有变现没有反哺 → 平台失去非遗属性与院团支持
- 只有反哺没有参与 → 回到"保护靠拨款、传承靠情怀"的老路

## 三、用户成长体系

### 3.1 积分体系：「戏份」

所有创作行为统一积分化，与现有产品模块一一对应：

| 行为 | 依托模块 | 戏份奖励 |
|---|---|---|
| 修复任务认领并完成 | 数字化修复 | +20 ~ 40 |
| 上传素材被下载 | 数字资产库 | 每次下载 +2 |
| 词条补充被采纳 | 川剧智库 | +10 |
| 课程学完并通过考核 | Skills 库 | +30 |
| 挑战赛投稿 | 短视频挑战 | +50 |
| 剧本 / 工作流被他人复用 | 虚实轻剧 / 创意工坊 | 按次分成（见 4.3） |

### 3.2 等级体系：「科班五级」

| 等级 | 名称 | 达成条件 | 核心权益 |
|---|---|---|---|
| L1 | 学徒 | 注册即授 | 可接任务赚戏份、学习免费课程 |
| L2 | 龙套 | 累计 500 戏份 | 素材可上架资产库，授权分成 50% |
| L3 | 角儿 | 累计 2000 戏份 + 3 件过审作品 | 作品可进 IP 授权库（分成 60%）；设计可上架文创商城 |
| L4 | 名角 | 累计 8000 戏份 + 官方认证 | 可在 Skills 库开课收学费（分成 70%）；享受官方联名优先权 |
| L5 | 台柱 | 年度评选 / 院团特聘 | 定制 AI 分身、演出票务分成、年度数字展位 |

> 关键原则：**等级不只是荣誉，直接挂钩收益比例与变现通道**。让用户清楚看到"升一级多赚多少钱"。

### 3.3 人设化激励（与现有功能联动）

利用平台已有的**脸谱 MBTI 测试**结果做任务智能匹配：

| 脸谱人格 | 推送任务类型 |
|---|---|
| 红脸（关羽型·行动派） | 短视频挑战、限时修复冲刺 |
| 黑脸（张飞型·实干家） | 数字化修复、素材批量整理 |
| 白脸（曹操型·谋略家） | 剧本创作、工作流设计、词条考据 |
| 花脸（包公型·守护者） | 内容审校、史实核查、版权巡查 |

人设匹配 → 任务完成率高 → 戏份积累快 → 正向循环。

## 四、六大变现通道

按落地难度从低到高排序：

### 4.1 任务赏金（落地最快）

- **模式**：院团 / 文博单位 / 品牌方发布真实需求（老照片修复、老唱片降噪、戏服纹样补全、活动海报设计），用户认领完成，审核通过后戏份兑现金。
- **分成**：创作者 85%，平台 10%，非遗传承人/素材授权方 5%。
- **依托模块**：数字化修复（已有任务大厅与认领流程）+ 任务广场扩展。
- **启动动作**：川剧院先放 50 个真实修复/设计需求，树标杆。

### 4.2 素材授权分成

- **模式**：创作者上传脸谱纹样、贴图、音频、3D 模型至数字资产库，设置免费/付费授权；被商用授权购买时自动分账。
- **分成**：按等级 50% ~ 70%（见 3.2）。
- **依托模块**：数字资产库（已有分类/预览/下载量数据）+ IP 资产库（授权申请流程已有）。
- **改造点**：资产库增加"创作者上传"入口与结算账户。

### 4.3 Skill / 工作流售卖

- **模式**：用户把调教好的 Agent 配置（如"川剧短视频五步流水线""脸谱设计工作流"）封装成模板上架，其他用户一键复用，按次/按订阅付费。
- **分成**：创作者 60%，平台 40%。
- **依托模块**：创意工坊 2.0（模板体系已有）+ 智能体矩阵（配置能力已有）。
- **对标**：Liblib Skill Hub 上线即聚合 200+ 专业创作者，官方配套 1000 万现金激励池。
- **启动动作**：首期官方悬赏 30 个高质量工作流模板，每个 ¥1000 ~ 3000 收编。

### 4.4 IP 授权分成（长线核心）

- **模式**：二创作品经 IP 铸造确权（时间戳 + 哈希存证）后进入授权库，面向品牌方/出版方/游戏厂对外授权，创作者持续抽成。
- **分成**：创作者 ≥50%，院团（IP 源头方）30%，平台 ≤20%。
- **依托模块**：IP 铸造（已有）+ IP 资产库（已有授权申请 Modal）。
- **合规要点**：院团官方 IP（名角肖像、经典剧目形象）设"官方授权池"，二创商用必须走池内授权，避免侵权纠纷。

### 4.5 课程分成

- **模式**：L4 名角可在 Skills 库开付费课（唱念做打、绝活分解、AI 辅助创作），高等级用户可申请做助教批改作业拿分成。
- **分成**：讲师 70%，助教 10%，平台 20%。
- **依托模块**：Skills 库（课程/课时/进度体系已有）。
- **社会价值**：数字学徒制降低传承门槛，解决"传习周期长、老龄化"痛点。

### 4.6 商品入驻

- **模式**：L3 角儿以上的二创设计可直接上架文创商城实体商品（按需印制，零库存），按销售额分成。
- **分成**：创作者 25% ~ 40%（含生产成本），平台 15%。
- **依托模块**：文创商城（商品体系已有）+ 按需印制供应链（外接）。

## 五、冷启动方案（前 3 个月）

### 5.1 官方任务首发（第 1 个月）

- 川剧院发布 50 个真实需求 + **首期 5 万元奖金池**
- 每个需求设"示范案例"（官方先做一个标准成品），降低参与心理门槛
- 目标：让第一批 100 个用户真实赚到钱——**赚到钱的用户是最好的宣传员**

### 5.2 高校渗透（第 2 个月起持续）

- 对接川内高校：戏曲社团、美术学院、数字媒体专业、计算机学院
- 办"数字学徒训练营"：6 周一期，导师带教 + 平台算力补贴 + 结业证书
- 双激励：学分/实习证明（校方）+ 等级直升 L3（平台）
- 对标："AI 遇见非遗"众创计划的产教融合协作体模式

### 5.3 名家带徒直播（贯穿）

- 名角每月 2 场直播：教课 + 现场点评学员作品
- 直播间直接挂任务入口与课程入口，边看边做边转化
- 优质学员作品直播间展示，满足社交展示需求

### 5.4 传播裂变

- 短视频挑战赛绑定话题（#川剧变脸挑战），季度评选，获奖作品获 IP 授权加速通道
- 脸谱 MBTI 结果页增加"分享海报"（带脸谱形象 + 人格描述 + 邀请码），低门槛拉新
- 剧本杀/虚实轻剧结局卡一键分享，游戏化产品自带传播属性

## 六、风控与合规（必须前置设计）

### 6.1 内容审核：机审 + 人审双道关

- 第一道：创意工坊"审校官 Agent"机审（术语准确性、史实核查、版权相似度检测）
- 第二道：人工抽检（L4 以上用户内容抽检 10%，L2 以下全检）

### 6.2 版权确权

- 所有上传素材/作品强制走 IP 铸造存证（时间戳 + 内容哈希），确权在先
- 院团官方 IP 设白名单授权池，二创商用必须走池内授权
- 上传时签署《原创性与授权承诺书》，训练素材需标注来源（吸取 Liblib 版权冻结分成教训）

### 6.3 提现与反刷

- 起提线 ¥100，T+7 结算
- 新账号分成阶梯释放：首月 30%、次月 50%、第三月 100%（防批量小号）
- 同设备/同支付账号关联检测，异常账号冻结分成
- 任务类收益设单人月度上限（如 ¥3000），超限转戏份

### 6.4 分成兜底原则

- 创作者分成比例在任何通道不低于 50%（素材/授权类）
- 平台调整分成比例需提前 30 天站内信 + 短信告知（对标 Liblib 协议条款）

## 七、运营指标体系

### 7.1 北极星指标

**月活跃创作者人均月收益中位数**——该指标同时反映参与度、变现能力与口碑。

### 7.2 分层指标

| 层级 | 指标 | 目标值（6 个月） |
|---|---|---|
| 参与 | 创作渗透率（浏览 → 投稿转化） | ≥ 8% |
| 参与 | 次周留存率（投稿用户） | ≥ 35% |
| 供给 | 素材复用率（下载/上传比） | ≥ 5:1 |
| 变现 | 活跃创作者中月入 ≥ ¥300 的比例 | ≥ 20% |
| 变现 | 任务完成周期中位数 | ≤ 5 天 |
| 生态 | L3 以上创作者数量 | ≥ 200 人 |
| 反哺 | 累计修复非遗物料数 | ≥ 300 件 |

### 7.3 数据看板需求

创作者侧：戏份余额、累计收益、等级进度、任务完成率
运营侧（admin 后台）：GMV 分通道统计、创作者分层漏斗、内容审核队列、提现风控预警

## 八、阶段性路线图

| 阶段 | 时间 | 目标 | 关键动作 |
|---|---|---|---|
| P0 筹备期 | 第 1 个月 | 基础设施就绪 | 上线创作者中心（等级/戏份/收益看板）、结算与提现系统、审核流程、协议文本 |
| P1 冷启动 | 第 2 ~ 3 个月 | 首批用户赚到钱 | 50 个官方任务 + 5 万奖金池、首批高校训练营、名角直播开跑 |
| P2 供给扩张 | 第 4 ~ 6 个月 | 变现通道全开 | 素材分成、工作流售卖、课程分成陆续上线；L3 创作者 ≥ 200 |
| P3 生态闭环 | 第 7 ~ 12 个月 | IP 授权跑通 | 官方授权池对接首批品牌方；文创商城创作者入驻；年度"台柱"评选 |

## 九、产品落地建议（近期开发项）

1. **创作者中心页面**（最高优先级）：等级进度、戏份余额、收益看板、任务大厅四合一——既是功能，也是向院方/合作方演示运营模式的展示页
2. **数字资产库增加"创作者上传"入口** + 结算账户体系
3. **任务广场增加"赏金任务"类型**：对接真实需求方，展示金额与截止时间
4. **MBTI 结果页增加分享海报**：低成本拉新抓手
5. **admin 后台增加运营看板**：创作者分层、审核队列、提现管理
