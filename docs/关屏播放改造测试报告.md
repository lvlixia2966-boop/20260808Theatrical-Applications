## 4. 预期真机行为（基于平台规范）

| 平台 | 点播音频（介绍/典故） | 收听席（PCM 流） |
|---|---|---|
| Android Chrome | **锁屏后继续播放**，通知栏/锁屏显示脸谱封面播放卡片，可控播放/停止 | Wake Lock 生效则屏幕常亮不中断；不支持时静默降级 |
| iOS Safari | 锁屏即暂停，锁屏卡片可**一键续播** | Wake Lock iOS 16.4+ 部分支持；不支持则行为同旧版 |

## 5. 遗留项与建议

1. **真机回归（必做）**：本次桌面环境无法验证锁屏行为，上线前须在 Android + iOS 真机各一台完整走一遍 §3 用例（尤其 I-2 锁屏卡片、W-2 屏幕常亮授权弹窗）。
2. **收听席深度优化（可选）**：AudioContext 播 PCM 流是关屏即停的根因；如需"收听席也能锁屏播"，需后端增加 HTTP 音频流（PCM→AAC/Opus）+ 收听席改 `<audio>` + MediaSession，属独立改造项。
3. **版本参数维护**：后续修改 `assets/js/*.js` 记得同步更新 `?v=` 参数，否则用户浏览器可能继续使用旧缓存。
4. **耗电提示**：收听席保屏会略增耗电，属产品取舍（观剧场景本需看字幕）；如反馈耗电明显，可改为"仅在原声开启时保屏"。
