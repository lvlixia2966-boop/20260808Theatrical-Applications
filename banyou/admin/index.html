API 接入说明

开放接口（游客端 / 三方平台，只读）

接口说明
GET /api/v1/bootstrap应用冷启动：公开设置 + 区域列表（一次拉全）
GET /api/v1/scenic-areas景区列表，支持 ?region=liangshan&city=西昌市&keyword=泸沽湖
GET /api/v1/scenic-areas/{id}景区详情（含点位与路线）
GET /api/v1/spots/{id}点位详情（多语言讲解稿、音频、坐标、触发半径）
GET /api/v1/routes/{id}伴游路线详情（按 seq 有序点位）
GET /api/v1/nearby?lat=&lng=按距离排序的附近景区

管理接口（JWT 鉴权）

前缀 /api/admin：登录 POST /login；景区/点位/路线/区域 CRUD；PUT /routes/{id}/stops 路线排点；GET/PUT /settings 应用设置；POST /uploads 素材上传（图片/音频，≤20MB）。鉴权方式：Authorization: Bearer <token>。
